# BookBot

A simple script that reads a book and prints a report with the total word count and character frequency.

## Usage

```sh
python3 main.py <path_to_book>
```

## Example

```sh
python3 main.py books/frankenstein.txt
```

```
============ BOOKBOT ============
Analyzing book found at books/frankenstein.txt...
----------- Word Count ----------
Found 75767 total words
--------- Character Count -------
e: 46043
t: 30365
a: 26743
o: 25225
...
============= END ===============
```
